# AI Job Agent 技术决策记录

## 岗位JD分析输出格式

- 问题：大模型自由文本不稳定，无法可靠参与岗位匹配计算。
- 选择：使用Pydantic `JobRequirementResult`约束Structured Output。
- 备选方案：直接返回自然语言或手动解析普通JSON。
- 为什么选择：字段稳定、自动验证、便于前端展示和后续评分。
- 缺点：修改输出字段时，需要同步调整后端Schema和前端显示。
- 未来升级：增加Timeout、Retry、Token成本记录和Redis缓存。

## AI测试模式

- 问题：开发期间重复调用真实模型会产生费用，并受网络波动影响。
- 选择：通过`LLM_MOCK_MODE`在模拟结果和真实模型之间切换。
- 备选方案：每次都调用真实模型。
- 为什么选择：测试速度快、结果稳定、不会产生Token费用。
- 缺点：模拟结果不能证明真实模型效果。
- 未来升级：上线前关闭Mock，并建立真实岗位评测集。
